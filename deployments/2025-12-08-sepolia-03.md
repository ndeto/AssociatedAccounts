## What's New in This Deployment

### Updatable Prefix Feature
This deployment introduces an **updatable text record prefix** to enable flexible ENS namespace management without redeployment.

**Key Features:**
1. ✅ **Owner-controlled prefix updates** via `setTextRecordPrefix()`
2. ✅ **Initial prefix**: `eth.ecs.controlled-accounts:` (instead of hardcoded `controlled-accounts:`)
3. ✅ **Ownership transfer** via `transferOwnership()`
4. ✅ **Backward compatible** - all core functionality remains the same

**New Functions:**
```solidity
function setTextRecordPrefix(string calldata newPrefix) external onlyOwner
function transferOwnership(address newOwner) external onlyOwner
```

**Public State Variables:**
```solidity
string public textRecordPrefix;  // Current prefix
address public owner;             // Contract owner
```

## Usage

### Query Controlled Accounts
To query controlled accounts using ENS text records with the new prefix:

**ENS Query Key**: `eth.ecs.controlled-accounts:<id>`

Example:
- `eth.ecs.controlled-accounts:0` → Returns YAML-encoded ControlledAccounts struct

### Update Prefix (Owner Only)
```javascript
// Only the deployer can update the prefix
await ccResolver.setTextRecordPrefix("new.prefix:");
```

### Transfer Ownership
```javascript
await ccResolver.transferOwnership(newOwnerAddress);
```

## ENS Text Record Format

**Key Pattern**: `eth.ecs.controlled-accounts:<id>`

**Value Format** (YAML):
```yaml
id: 0
registeredAt: 1733698801
parent: "0x00010000aa36a7147e5f4552091a69125d5dfcb7b8c2659029395bdf"
children:
  - "0x00010000aa36a7142b5ad5c4795c026514f8317c7a215e218dccd6cf"
  - "0x00010000aa36a7146813eb9362372eef6200f3b1dbc3f819671cba69"
```

**Address Format**: ERC-7930 Interoperable Addresses (v1)
- `0x0001` - Version 1
- `0000` - Reserved
- Next 2 bytes - Chain type (EVM)
- Next variable bytes - Chain ID
- Final 20 bytes - Ethereum address

## Integration

### Read Controlled Accounts
```javascript
const CCResolver = await ethers.getContractAt(
  "CCResolver",
  "0xCE943F957FC46a8d048505E6949e32201a128f84"
);

// Query by ID
const node = ethers.namehash("yourname.eth");
const yaml = await CCResolver.text(node, "eth.ecs.controlled-accounts:0");
console.log(yaml);
```

### Register New Controlled Accounts
```javascript
// 1. Create associations in AssociationsStore (with signatures)
// 2. Register in CCResolver
const parentAccount = "0x0001..."; // ERC-7930 format
const childAccounts = ["0x0001...", "0x0001..."];
const id = await CCResolver.registerControlledAccounts(parentAccount, childAccounts);
console.log("Registered with ID:", id);
```
