## What's New in v0.1.0

### Full ENS Resolver Support
This version transforms CCResolver into a complete ENS resolver while maintaining controlled accounts functionality.

**New Features:**
1. ✅ **Text Records** - Standard ENS text record support (ENSIP-5)
2. ✅ **Data Records** - Binary data storage support
3. ✅ **Address Records** - Multi-coin address support (ENSIP-11)
4. ✅ **Contenthash** - IPFS/Arweave content hash support
5. ✅ **ERC-165 Support** - Interface detection via `supportsInterface()`
6. ✅ **Comprehensive Events** - Events for all record changes
7. ✅ **Backward Compatible** - Controlled accounts functionality preserved

**New Functions:**
```solidity
// Setters (owner-only)
function setText(string calldata _key, string calldata _value) external onlyOwner
function setData(string calldata _key, bytes calldata _data) external onlyOwner
function setAddr(address _addr) external onlyOwner
function setAddr(uint256 _coinType, bytes calldata _value) external onlyOwner
function setContenthash(bytes calldata _hash) external onlyOwner

// Getters (public)
function text(bytes32 node, string calldata _key) external view returns (string memory)
function data(bytes32 node, string calldata _key) external view returns (bytes memory)
function addr(bytes32 node, uint256 _coinType) external view returns (bytes memory)
function contenthash(bytes32 node) external view returns (bytes memory)
function supportsInterface(bytes4 interfaceId) external pure returns (bool)
```

## Usage

### Setting Resolver Records (Owner Only)

```javascript
const resolver = await ethers.getContractAt(
  "CCResolver",
  "0xAE5A879A021982B65A691dFdcE83528e8e13dFd3"
);

// Set text record
await resolver.setText("resolver-info", "# CCResolver v0.1.0...");
await resolver.setText("avatar", "https://example.com/avatar.png");
await resolver.setText("com.twitter", "@alice");

// Set address
await resolver.setAddr("0x1234567890123456789012345678901234567890");

// Set contenthash (IPFS)
const ipfsHash = "0xe301017012204edd2984eeaf3ddf50bac238ec95c5713fb40b5e428b508fdbe55d3b9f155ffe";
await resolver.setContenthash(ipfsHash);

// Set data record
await resolver.setData("proof.data", ethers.utils.defaultAbiCoder.encode(["uint256"], [12345]));
```

### Querying Records

```javascript
const node = ethers.utils.namehash("yourname.eth");

// Query text
const resolverInfo = await resolver.text(node, "resolver-info");
const avatar = await resolver.text(node, "avatar");

// Query address
const ethAddr = await resolver.addr(node, 60); // Coin type 60 = Ethereum

// Query contenthash
const contentHash = await resolver.contenthash(node);

// Query data
const data = await resolver.data(node, "proof.data");

// Query controlled accounts (still works!)
const yaml = await resolver.text(node, "eth.ecs.controlled-accounts:0");
```

### Setting resolver-info

Use the included script to set resolver metadata:
```bash
./script/SetResolverInfo.sh
```

This sets a concise resolver-info text record following the [resolver-info ENSIP standard](https://github.com/nxt3d/ensips/blob/resolver-info-metadata/ensips/resolver-info-text-record.md).

## ENS Text Record Format

### Controlled Accounts
**Key Pattern**: `eth.ecs.controlled-accounts:<id>`
**Value**: YAML-formatted struct with verified parent and children accounts

### Standard ENS Records
- **resolver-info**: Metadata about this resolver (version, features, etc.)
- **avatar**: Avatar image URL
- **com.twitter**, **com.github**, etc.: Social profiles
- Any custom text key-value pairs
